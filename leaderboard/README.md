# leaderboard/ — 排行榜、运行台账与盲评中心目录

本目录承载全流程的匿名盲评交接、生命周期留档与最终总榜合成：

| 路径 | 角色可见性 | 说明 |
| --- | --- | --- |
| `scores.md` | 出榜完成后公开 | 由 `finalize.py` 自动重算并合成的总榜与各模型客观测量/盲评明细表 |
| `verdicts/<模型>.json` | 出榜完成后公开 | 每个规范模型 ID 的完整结构化裁决留档（含均值、极差半宽、各批次明细与盲评包关联） |
| `blind/<pack_id>/` | **评委盲评阶段唯一输入** | 由 `judge_pack.py` 生成的匿名盲评包（含 10 张《交互状态连环画》、客观物理批注、脱敏源码与说明文档，绝不含模型名与 A/B/C 分数） |
| `blind-maps/*.json` | **仅出榜阶段读取** | 匿名包 `pack_id`/`case_id` 到真实模型与运行目录的私有映射（盲评阶段严禁评委读取） |
| `reviews.jsonl` | **评委盲评只写不读** | 由 `judge_submit.py` 加锁原子追加的中心评审日志 |
| `runs_log.jsonl` | 仅出榜与审计阶段可见 | 记录每次 `start`、`pack`、`finalize` 生命周期事件与哈希承诺的运行台账 |
| `finalize.py` | 盲评全部完成后执行 | 一键拉起无头浏览器三波剧本定稿客观分并合成总榜的快捷入口 |
