# 排行榜 · creator-hub-xiaonuo

> D 层美学质感、耦合工作台微交互与工程可维护性评分（30 分）由独立评委审阅匿名盲评包后通过 `judge_submit.py` 追加至中心日志 `leaderboard/reviews.jsonl`；
> A/B/C 连环组合压测与物理可用性客观分（70 分）在评委盲评全部完成后，由 `finalize.py` 现场统一拉起无头浏览器执行三波确定性标准剧本测量合成。

> **当前版本：`xiaonuo-v3.0`**（历史 `xiaonuo-v2.0` 与 `xiaonuo-v1.0` 归档榜单及全量留档分别见 `leaderboard/archive/xiaonuo-v2.0/scores.md` 与 `leaderboard/archive/xiaonuo-v1.0/scores.md`）。

## 赛制口径

| 维度 | 规则 |
| --- | --- |
| 任务形态 | 独立 AI 研究者“林澈”的离线耦合顾问工作台与实测文集（双击 `index.html` 本地 `file://` 直接运行，零外网依赖） |
| 悖论拆解 | 主干入口规定最小 `data-testid` 契约；`TASK.md` 聚焦深层耦合业务场景与四大真实痛点，不喂防御性工程清单 |
| 连环过关 | A2/A3/A4 三大主干链均实行**顺序连坐门控**（任一上游步骤得分率 `< 55%`，后续下游步骤均乘以 `0.20` 衰减），大幅压缩静态保底分（A1 压至 2.5 分）：覆盖原生 `<svg>` 多维能力图动态重绘、分阶段里程碑拆解、繁忙档期冲突检测与一键顺延、跨模块 Undo/Redo 历史栈（含输入框防劫持）、耦合方案非破坏带入与连续历史栈 |
| 物理压测 | 第二波：四档视口（含表格长文与 SVG 对比面板）反截断几何、320px 超长串抗撑破、多态脏存储容错与陡峭 WCAG AA 9 角色木桶对比度（`min_weight=0.65`）；第三波：6 区键盘可达、对比弹层双向焦点锁（`Tab` + `Shift+Tab`）与 Esc 归位、反空转 `rAF` 及 320 卡高压渲染延迟 |
| 计时口径 | B2 采用端到端真实墙钟（`start_run.py` 打 `t0` → `judge_pack.py` 冻结 `t1` 并锁定代码 SHA-256）；22 分钟内满分，之后每 26 分钟减半；B1/B2 均以 A 层得分率封顶 |
| 盲评隔离 | `judge_pack.py` 充当“替身体验官”抓拍 12 张《交互状态连环画》（`S01`–`S12`）并附纯物理事实批注，连同脱敏源码打入 `leaderboard/blind/<pack_id>/`（绝不含模型名与客观分）；评委按三步取证法与反端水铁律独立盲评 |
