# 计分细则 · creator-hub-xiaonuo v4.0

总分 **100 分** = **A 异步状态韧性与耦合工作台（30） + B 高压性能与开发效率（15） + C 严苛物理可用性底线（25） + D 视觉美学、交互直觉与工程架构（30）**。
所有阈值、连环门控参数、权重与分段线性插值节点统一存放在 [`configs/benchmark.json`](../configs/benchmark.json)。

## 1. A 层：异步状态韧性、去剧透耦合工作台与连环压测过关制（30 分，第一波无头剧本）

全程拦截并中止一切 `http/https/ws/wss` 外网请求，通过 `file://` 打开本地 `index.html` 并对接官方只读 `mock_backend.js`（`window.LincheMockAPI`）。若保留 `data-unimplemented="true"`、无法加载或篡改了 `mock_backend.js`（归一化 SHA-256 不匹配），对应关卡或整轮客观层直接判失分。

### 连环组合过关门控（Sequential Chained Gauntlet）
- `A2`、`A3`、`A4` 三条核心业务长链均按关卡顺序执行上游及格门控（`pass_threshold = 0.55`）；
- 一旦某链上游关卡原始得分率 `< 0.55`，该链后续所有下游关卡得分率统一乘连坐折算系数 **`0.20`**，杜绝“上游异步状态已错乱却靠下游孤立小点拿高分”。

## 3. B 层：高压性能与开发效率（15 分，以 A 层得分率封顶）

设 A 层封顶乘数：
$$\text{cap\_factor} = \min\left(1.0,\ \frac{A}{30.0 \times \text{cap\_a\_ratio}}\right) \quad (\text{默认 } \text{cap\_a\_ratio} = 1.0)$$

- **B1 高压规模性能与反空转（满分 5.0）**：
  - 离线首屏双帧就绪耗时 `first_paint_ms`（权重 15%，`≤240ms` 满分）
  - 注入 **320 张高压 DOM 卡片**后连续 14 次高频搜索回流响应 `search_p95_ms`（权重 50%，`≤45ms` 满分，`≥300ms` 为 0）
  - 扩展 24 节长文后连续滚动帧间隔 `scroll_frame_p95_ms`（权重 35%，`≤20ms` 满分，`≥120ms` 为 0）
  - 若静默 200ms 检出空闲无限 `requestAnimationFrame` 空转循环，直接乘惩罚系数 `0.60`（扣减 **40%**）
  - 最终得分：$B_1 = \min\left(B_{1,\text{raw}},\ 5.0 \times \text{cap\_factor}\right)$。
- **B2 端到端开发耗时（满分 10.0）**：
  - 免除选手编造静态文案后，真实墙钟分钟数 $m = (t_1 - t_0) / 60$ 的满分窗口设为 $m_0 = 18$ 分钟，半衰期 $h = 24$ 分钟：
    $$B_{2,\text{raw}} = 10.0 \times 0.5^{\max(0,\, m - 18.0) / 24.0}$$
  - 最终得分：$B_2 = \min\left(B_{2,\text{raw}},\ 10.0 \times \text{cap\_factor}\right)$。
